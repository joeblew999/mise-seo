# mise-seo-template

A repo with [mise-seo](https://github.com/joeblew999/mise-seo): its pins and mise tasks kept by it.

```sh
mise install                 # node, aube, mise-seo, the Go go.mod names
mise run setup               # the packages
mise run mise-seo          # what's done, and what to run next
mise run app:start           # the app
mise run mise-seo:update   # every pin at its newest release, in one go
```

How mise-seo works here: [docs/mise-seo/README.md](docs/mise-seo/README.md).
